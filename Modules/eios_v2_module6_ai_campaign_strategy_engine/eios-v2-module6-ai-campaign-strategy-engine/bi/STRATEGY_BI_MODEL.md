# Strategy BI Model

## Measures
- Recommendation Count
- Urgent Recommendation Count
- Accepted Strategy %
- Implemented Strategy %
- Message Persuasion Score
- Message Risk Score
- Resource Allocation by Area
- Risk Count by Level
- Action Completion Rate

## Dimensions
- Candidate
- Area
- Segment
- Issue
- Survey Wave
- Strategy Session
- Recommendation Type
- Priority
- Action Owner
