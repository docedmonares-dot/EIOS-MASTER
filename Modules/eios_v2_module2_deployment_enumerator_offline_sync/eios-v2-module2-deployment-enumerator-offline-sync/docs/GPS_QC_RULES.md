# GPS and QC Rules

## GPS Status

- Valid
- Warning
- Invalid
- Missing
- Out of Area

## QC Precheck Status

- Valid
- Warning
- Blocked
- For Supervisor Review

## Blocking Flags

- Missing GPS
- Missing respondent code
- Missing required answers
- Invalid assignment
- Invalid survey version

## Warning Flags

- Weak GPS Accuracy
- Interview too short
- Duplicate respondent code
- Duplicate GPS
- Out-of-area warning
- Quota completed
